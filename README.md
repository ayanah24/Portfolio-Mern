# 🧑‍💻 Full-Stack Developer Portfolio

A modern, full-stack MERN portfolio website with a secure admin panel to manage projects, contacts, and resume — built with React.js, Node.js, Express.js, and MongoDB.

🔗 **Live Demo:** [portfolio-mern-tawny.vercel.app](https://portfolio-mern-tawny.vercel.app)  

---

## ✨ Features

- 🎨 Responsive, modern UI with dark theme and gradient animations
- 🔐 JWT-based authentication for secure admin access
- 🔑 Google OAuth 2.0 login
- 🗂️ Admin panel to add, edit, and delete projects
- 📬 Contact form with MongoDB persistence
- 📄 Dynamic resume link management via admin dashboard
- 🌐 CORS-configured REST API with protected routes

---

## 🛠️ Tech Stack

| Layer | Technologies |
|---|---|
| Frontend | React.js, Vite, Tailwind CSS, Axios |
| Backend | Node.js, Express.js |
| Database | MongoDB (Mongoose) |
| Auth | JWT, Google OAuth 2.0 (Passport.js) |
| Deployment | Vercel (Frontend), Render (Backend) |
